# Lemos a Palavra

criar um site infantil e religioso em estilo cartoon, com a pagina inicial em anexo 1, manter todas imagens, apenas deixar clicavel a imagem de cadastro ou entrar, e depois de criar esta pagina de cadastro, quando o usuario entrar, ira visualizar a pagina totalmente ativa conforme anexo 2.
Deixe todos os icones girando ao entorno do icone central, com velocidade media, de forma que o usuario sempre leia ela e ative quando quiser 
Tenho todas as imagens individuais se precisar
