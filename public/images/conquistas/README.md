# Ícones dos níveis de conquistas

Esta pasta guarda os seis ícones individuais dos Tesouros da Palavra, com fundo transparente, em formato WebP.

- `nivel-bronze.webp`
- `nivel-prata.webp`
- `nivel-ouro.webp`
- `nivel-esmeralda.webp`
- `nivel-rubi.webp`
- `nivel-diamante.webp`

As medalhas serão exibidas ao lado do avatar conforme o nível do usuário. Os arquivos de imagem ainda precisam ser enviados.
